# LiquorPro – Sistema Inteligente de Gestión para Licorerías

## 1. Descripción general
LiquorPro es un sistema web orientado a la gestión de ventas, compras e inventario de una licorería. El sistema permitirá administrar productos, categorías, proveedores, clientes, usuarios, ventas, compras, movimientos de inventario, reportes y auditoría de acciones.

## 2. Objetivo general
Desarrollar un sistema web inteligente para optimizar la gestión de ventas e inventario de una licorería, aplicando Scrum, desarrollo guiado por especificaciones, pruebas automatizadas y control de calidad de software.

## 3. Módulos principales
- Seguridad y autenticación.
- Gestión de usuarios y roles.
- Gestión de productos.
- Gestión de categorías.
- Gestión de proveedores.
- Gestión de clientes.
- Gestión de compras.
- Gestión de ventas.
- Movimientos de inventario.
- Dashboard inteligente.
- Reportes.
- Auditoría.

## 4. Tecnologías
- Frontend: React + Vite + Tailwind CSS.
- Backend: Node.js + Express.
- Base de datos: MySQL.
- ORM: Prisma.
- Pruebas: Jest + Supertest.
- Control de versiones: Git y GitHub.
- IDE: Visual Studio Code.

## 5. Enfoque metodológico
El proyecto se desarrollará usando Scrum para la gestión iterativa del trabajo y Spec-Driven Development para guiar la generación del código a partir de especificaciones funcionales y técnicas.
