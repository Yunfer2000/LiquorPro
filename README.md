# LiquorPro

Sistema web para la gestión de inventario, compras, ventas, clientes, proveedores y reportes de una licorería.

## Tecnologías utilizadas

### Backend
- Node.js
- Express
- Prisma ORM
- MySQL
- JWT
- Bcrypt

### Frontend
- React
- Vite
- Tailwind CSS
- Axios
- Recharts
- jsPDF
- XLSX

## Requisitos

Antes de ejecutar el proyecto se debe tener instalado:

- Node.js
- MySQL Server
- MySQL Workbench
- Git
